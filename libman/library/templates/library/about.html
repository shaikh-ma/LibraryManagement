Welcome !!!


BOOKIPEDIA is my final year project on the topic of "Library Management System".
My name is Shaikh Mohammed Affan, I'm a T.Y BSc. IT student at KES College, Khar.

As a part of my project this is the website that I've created for a comprehensive system for Library Management. This project includes most of the functionalies that are used in management of college library on a daily basis. The website is designed in such a way that almost anyone wheter they are a student of the college or not, teachers or any staff of the college can register to the website and can request a book from the library for a specific time.

The admin of the libarary can handle the tasks such as assigning books to the requesting users, confirming the returned book as well as view the penalities on which users and books exists.

The user interface is very simple yet elegant and allows the user to quickly get started using it. The home page shows the list of all the books present in the library while also indicating that whether its available or not. The admin and the users can view which books they've borrowed and requested, and also view their status.
