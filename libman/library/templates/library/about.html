BOOKIPEDIA is a Library Management project created in Django.

As a part of learning Django, I created this project which is a web-app that can be used for a comprehensive system for a Library Management System.
This project includes most of the functionalies that are commonly used in management of small libraries.
The web-app is designed in such a way that almost anyone whether they are a student of the college or, teachers or any staff of the college can register to the website and can request a book from the library for a specific time.

The admin of the libarary can handle the tasks such as assigning books to the requesting users, confirming the returned book as well as view the penalities on which users and books exists.

The user interface is very simple yet elegant and allows the user to quickly get started using it. The home page shows the list of all the books present in the library while also indicating that whether its available or not. The admin and the users can view which books they've borrowed and requested, and also view their status.
